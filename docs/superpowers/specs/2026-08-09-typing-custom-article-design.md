# Typing Test: Custom Article Upload

## Goal
Allow users to upload a local `.txt` (zh/en) and practice typing the full article in order.

## Behavior
- Source toggle: built-in word bank | my article
- Upload `.txt` ≤ 200KB, UTF-8 preferred; stored locally (localStorage)
- Practice text in original order; duration options still apply
- Built-in difficulty flow unchanged

## UI
- Settings: source options + upload button + file name
- Hide/disable language & difficulty when using custom article
